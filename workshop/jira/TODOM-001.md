# TODOM-001: User can see a list of todos

**Type:** User Story
**Status:** Pending
**Created:** 2026-03-01

## Summary

As a user, I want to see my todos when I open the app, so that I know what I need to do.

## Acceptance Criteria (Story-Level PATs)

1. Todos are displayed on load
   - When the user opens the app, a list of todos is displayed
   - Each todo shows its title and completion status

2. Empty state is handled
   - When there are no todos, a "No todos yet" message is shown
