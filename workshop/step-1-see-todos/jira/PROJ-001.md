# PROJ-001: User can see a list of todos

## Description
As a user, I want to see my todos when I open the app,
so that I know what I need to do.

## Acceptance Criteria
- AC-001: When the user opens the app, a list of todos is displayed
- AC-002: Each todo shows its title and completion status
- AC-003: When there are no todos, a "No todos yet" message is shown
