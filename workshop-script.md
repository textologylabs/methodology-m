## Workspace Convention

The `workshop/workspace/` folder holds all generated artefacts produced during the workshop. These files are outputs of M Power actions — not source material. They can be deleted and regenerated by replaying the steps.

```
workshop/
  jira/               ← source inputs (static, hand-authored)
  workspace/
    jira/             ← generated: enriched stories, sub-tasks
```

When a power action generates a file (e.g. decomposed sub-tasks), it writes into `workspace/jira/`. Subsequent actions read from there, not from `jira/`.
