## Workspace Convention

The `workshop/workspace/` folder holds generated artefacts produced during the workshop. These files are outputs of M Power actions — not source material. They can be deleted and regenerated by replaying the steps.

```
workshop/
  jira/               ← source inputs (static, hand-authored)
  workspace/
    jira/             ← generated: enriched stories, sub-tasks, PATs (staging)
```

In the real M Power flow, there is no staging area — everything goes directly into the root repo. The workshop workspace exists because we're building the power incrementally and discovering the flow as we go. Once `bootstrap-root-repo` is operational, the workspace becomes unnecessary.

## Step 3: Bootstrap Root Repo ⏳

**Rationale:** The root repo is the source of truth for the entire M-type project. It must exist before PATs can be generated or stories decomposed. The `bootstrap-root-repo` capability creates the repo and seeds it with the project manifest and Story Zero.

**What this step will do:**
1. Create `todo-m-root` repo in `methodology-m/todo-m-workshop`

4. Create conventional folder structure (`pats/`, `stories/`, `packages/shell/`)

## Design Decisions

### Bootstrap Sequencing

**Context:** While generating PATs for TODOM-000, we discovered a bootstrap paradox — PATs need to live in the root repo (`pats/`), but the root repo doesn't exist until Story Zero creates it.

**Resolution:** Bootstrap is a sequence of atomic capabilities, not a single big-bang operation:

1. `setup-workspace` — creates the GitLab group
2. `bootstrap-root-repo` — creates the root repo, seeds it with `project.yaml` and Story Zero
3. `generate-pats` — generates PATs and commits them to the root repo (delegated, not reimplemented)
4. `decompose-story` — decomposes into sub-tasks, creates managed repos

The root repo becomes the source of truth the moment it's created (step 2). Each capability stays atomic. `bootstrap-root-repo` orchestrates the sequence but delegates PAT generation to the existing `generate-pats` capability. The user has decision points between steps.

**Impact:**
- New M Power capability: `bootstrap-root-repo`
- Updated methodology paper (Sections 6 and 7) to reflect the sequencing
